# Личный Telegram-бот для учёбы

1. Открой @BotFather в Telegram, отправь /newbot и создай отдельного бота.
2. Распакуй архив. Открой PowerShell в папке study_bot и выполни:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

3. Вставь токен после TELEGRAM_BOT_TOKEN=, сохрани файл. Остальные поля пока
   можно оставить пустыми. Запусти:

```powershell
.\.venv\Scripts\python.exe bot.py
```

4. Открой своего бота в Telegram и вручную отправь /id. Скопируй число.
   Останови программу в PowerShell клавишами Ctrl+C.
5. В .env заполни TELEGRAM_OWNER_ID своим числом, а OPENAI_API_KEY ключом
   из https://platform.openai.com/api-keys. Для запросов нужен доступ к API
   и настроенная оплата. Храни .env у себя.
6. Запусти bot.py той же командой и отправь /start, затем текстовый вопрос
   и фото с подписью «Реши №4 по шагам». Прикрепляй изображение как фото.
   /reset очищает диалог. После перезапуска память тоже очищается.

Для каждого пользователя бот хранит в памяти до четырёх последних пар «вопрос — ответ», включая фото.
Этот контекст повторно отправляется в API при уточнениях и учитывается
в расходе. Запросы принимаются в личном чате от владельца и добавленных пользователей.
Для работы бот должен быть запущен. Если появится ошибка, посмотри статус
в PowerShell. 401 обычно связан с ключом, 429 — с лимитом или квотой.

## Как выдать доступ

1. Друг открывает бота, отправляет /id и пересылает тебе полученное число.
2. Ты пишешь боту /allow 123456789, подставив ID друга.
3. Друг отправляет текст или фото в личный чат бота.

Только владелец может использовать /allow ID, /deny ID и /users.
Список сохраняется в allowed_users.json рядом с bot.py. Сохрани этот файл
при переносе бота. У каждого пользователя отдельная история, /reset
очищает только свою. Все запросы используют ключ OpenAI владельца.

При обновлении уже установленного бота останови его, замени bot.py и
запусти снова. Сохрани существующий .env.
